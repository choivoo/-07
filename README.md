# 호그 사이클 로얄

실시간 1:1 타워 디펜스 카드 게임 (개인용, 단일 HTML). `index.html` 을 열면 바로 실행됩니다.

- 조작: 아래 카드를 끌어서 내 진영(파랑)에 놓기. 상단 왼쪽 스피커로 음소거.
- 입장 암호(가벼운 잠금)는 `index.html` 의 `ACCESS_HASH` 로 바꿀 수 있습니다. 기본 암호는 대화에서 안내했습니다.
- `assets/` : 원본 이미지와 분리/투명화한 결과물 (`cards/`, `map/`, `sprites/`).
- 개인/가족용 비공개 취미 프로젝트입니다. 사용된 이미지는 원 저작권자의 것이므로 재배포하지 마세요.
